# Parameter Sweep Heatmaps

## Purpose

Parameter heatmaps reveal whether an apparent edge is broad or merely a lucky point.

## Minimum grid record

- `run_id`
- `strategy_id`
- `parameter_1_name`
- `parameter_1_value`
- `parameter_2_name`
- `parameter_2_value`
- `CAGR`
- `Sharpe`
- `MaxDD`
- `Expectancy`
- `Turnover`
- `OOS_decay`

## Stable edge definition

A stable edge should have a neighborhood of acceptable cells around the best cell. Single-cell spikes are usually overfit.

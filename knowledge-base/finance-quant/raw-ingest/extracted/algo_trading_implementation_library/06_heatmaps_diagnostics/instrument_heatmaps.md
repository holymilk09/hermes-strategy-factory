# Instrument Heatmaps

## Use

Find whether edge is broad, symbol-specific, sector-specific, or liquidity-specific.

## Views

- Symbol x month PnL
- Symbol x regime Sharpe
- Sector x month PnL
- Liquidity bucket x expectancy
- Spread bucket x slippage
- Market cap bucket x win rate

## Red flags

- Most profit from one symbol.
- Losses hidden in lower-liquidity instruments.
- Strategy only works in names with unrealistic fills.

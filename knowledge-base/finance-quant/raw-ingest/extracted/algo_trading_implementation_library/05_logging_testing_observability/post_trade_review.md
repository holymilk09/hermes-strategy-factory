# Post-Trade Review

## Review fields

- Trade ID
- Strategy ID
- Entry signal reason
- Exit reason
- Expected holding period
- Actual holding period
- Entry slippage
- Exit slippage
- MAE
- MFE
- Realized PnL
- Regime bucket
- Mistake category if any

## Mistake categories

- Good process / bad outcome
- Bad signal
- Bad sizing
- Bad risk rule
- Bad execution
- Bad data
- Code bug
- Manual override
- Unknown

# Quant Metrics Catalog

This catalog is broad, not literally exhaustive. The practical goal is to cover the metrics a solo founder needs to build, diagnose, reject, and improve systematic strategies.

## Metric families

1. Performance: return, CAGR, Sharpe, Sortino, Calmar, Information Ratio.
2. Drawdown: max drawdown, duration, time under water, Ulcer Index, Pain Ratio.
3. Tail risk: VaR, CVaR, skewness, kurtosis, tail ratio, risk of ruin.
4. Trade quality: hit rate, payoff ratio, profit factor, expectancy, MAE/MFE.
5. Execution: slippage, implementation shortfall, fill rate, latency, reject rate.
6. Signal/model: IC, Rank IC, ICIR, calibration, Brier, precision/recall, drift.
7. Overfit validation: PSR, DSR, PBO, Newey-West t-stat, bootstrap CI, OOS decay.
8. Regime/microstructure: realized volatility, ATR, Hurst, half-life, breadth, imbalance.

See `all_quant_metrics_catalog.csv` for the machine-readable version.

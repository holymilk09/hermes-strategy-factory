# NautilusTrader Notes

NautilusTrader is worth studying for architecture: cache, message bus, portfolio, execution, adapters, deterministic simulation, logging, reconciliation, and live/backtest parity.

## Best use

- Multi-venue trading.
- Execution-heavy strategies.
- Crypto/perps/futures-style environments.
- Systems where backtest/live parity and order state are central.

## Caution

It is more complex than a simple research framework. Do not start here if the current bottleneck is just learning basic strategy validation.

# Data Vendors and Research Tools

## Databento

Best for serious historical market data, including APIs and reference data. Use when data quality, schema, and market-data depth matter.

## OpenBB

Best as a data connector/research layer. Useful for building financial dashboards, agent workflows, and quick access to multiple datasets.

## Polygon/Massive-style APIs

Best for accessible retail-to-prosumer equities/options/crypto data. Validate quality and limitations before relying on it for execution-sensitive strategies.

## Rule

Do not compare vendors only by price. Compare:

- Asset coverage
- Historical depth
- Tick/quote/bar availability
- Corporate actions
- Options chain completeness
- Rate limits
- Latency
- Adjustment policies
- Delisting coverage
- API reliability

# Agentic Workflow

## Standard task sequence

1. Read `README.md`, `project_rules.md`, and relevant contract files.
2. State intended file changes.
3. Modify the smallest possible surface area.
4. Run tests.
5. Produce diff summary.
6. Update run/review docs if strategy logic changed.

## Strategy implementation sequence

1. Add hypothesis file.
2. Add feature function.
3. Add signal function.
4. Add sizing config.
5. Add risk rule if needed.
6. Add tests.
7. Add backtest config.
8. Run baseline.
9. Generate report.
10. Write review.

# Backtest Contract

## Required inputs

- Strategy ID
- Config file
- Data version
- Start/end date
- Universe rule
- Cost model
- Slippage model
- Fill model
- Risk limits
- Random seed if stochastic

## Required outputs

- Run manifest
- Equity curve
- Order ledger
- Fill ledger
- Trade ledger
- Position ledger
- Metric pack
- Data quality report
- Review report

## Invariant

Same inputs must produce same outputs.

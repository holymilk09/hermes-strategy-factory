# 13F, Macro, and Alternative Data

## 13F

Use for slow institutional-positioning studies. Do not treat as real-time signal; filings are delayed and holdings can change before publication.

## Macro

Use release timestamps. Avoid revised-data leakage. Separate event avoidance from predictive macro modeling.

## Alternative data

Useful only if:

- Timestamp is reliable.
- Coverage is stable.
- Data generation process is understood.
- It can be joined without look-ahead.
- It improves OOS after costs.

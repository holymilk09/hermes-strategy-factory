# Cross-Asset Features

## Examples

- Equity index returns: SPY/QQQ/IWM.
- Volatility: VIX or realized vol proxy.
- Rates: 2Y/10Y yields, curve slope.
- Dollar: DXY proxy.
- Commodities: oil/gold.
- Credit: HYG/LQD or spread proxies.
- Crypto: BTC/ETH trend, funding, OI.

## Uses

- Risk-on/risk-off gates.
- Sector rotation context.
- Volatility targeting.
- Event avoidance.
- Macro shock detection.

## Caution

Cross-asset features can add complexity without edge. Each feature needs a reason and a falsification test.

# PDF downloads for Hedge Fund Analysis & 13F Literature

This runtime could not fetch PDF bytes into the filesystem because outbound DNS resolution failed during direct download attempts. The folder is intentionally left empty except for this note.

Use the root-level `download_open_pdfs.py` script and `DOWNLOAD_MANIFEST.csv` to download official free PDFs locally. The script validates that each downloaded file begins with a PDF header and records failures in `DOWNLOAD_RESULTS.csv`.

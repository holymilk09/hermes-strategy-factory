# Swing/Wave Detection (Non-Subjective)

## Definition (No Trendlines)
Swing high: high greater than N bars before AND N bars after
Swing low: low lower than N bars before AND N bars after

## Features
- swing_high_count, swing_low_count
- average_wave_duration, average_wave_return
- pullback_depth, retracement_ratio, extension_ratio
- days_since_last_swing_high, days_since_last_swing_low
- higher_low_sequence_count, lower_high_sequence_count
- range_compression_after_swing
- volume_dryup_after_swing

## Pattern Examples
- 3-push exhaustion
- Higher-low compression
- Lower-high compression
- Breakout after 2-week base
- Failed breakdown after undercut
- First pullback after expansion
- Inside-week breakout

# Compliance Language

Use this language consistently in all commercial pages and customer-facing copy.

## Required language

- Research-only tracking
- Not investment advice
- No live trading
- No broker execution
- No personalized financial advice

## Forbidden claims

Do not use:
- guaranteed returns
- proven winners
- trade alerts
- buy alerts
- sell alerts
- personalized financial advice
- live trading
- broker execution
- beat the market
- risk-free
- can’t lose
- prediction engine

## Footer language

Research-only: This report is for research tracking and education only. It is not investment advice. No live trading. No broker execution. No production activation.
